This page runs entirely client-side — it makes no network requests at all. Everything below comes from standard browser APIs (Navigator, Screen, WebGL2, WebGPU) evaluated live in your browser, right now.

Operating System

Derived from navigator.userAgentData (Client Hints, Chromium only) and/or navigator.userAgent/platform parsing. Modern Chrome intentionally "freezes" and generalizes the UA string (e.g. reports "Windows NT 10.0" for all Win10/11), so exact OS version is increasingly unavailable to scripts by design.

Device

Device type is inferred from touch support, screen size and UA hints — there is no direct "give me the model name" API for privacy reasons.

Memory & CPU

navigator.deviceMemory (Chromium only) reports RAM in coarse buckets (0.25–8, capped at "8" even if you have far more) specifically to limit fingerprinting. hardwareConcurrency is logical CPU threads, not physical cores, and Safari caps it.

Display

WebGL2 → GPU report

The unmasked renderer/vendor strings (via WEBGL_debug_renderer_info) are the most reliable way to identify the actual GPU from a browser. Firefox and Safari partially mask this by default in some configurations; Chrome usually exposes it.

WebGPU → Adapter report

WebGPU's requestAdapterInfo/adapter info can expose vendor, architecture and device strings on some browsers/flags; many ship it blank or omitted for privacy.
